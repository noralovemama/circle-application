试水
这版先验证 3 件事
  • 有没有人愿意发起固定 6 人的小局
  • 看到的人愿不愿意报名这种轻量线下碰头
  • 留言加微信群，能不能把第一次碰头顺利接住
所以这版先停在这里

发起、浏览、报名、留言、微信群协调。先别把完成状态、复盘、再约这些机制一次做太重。

Prototype Notes

这是什么

一个可直接打开的高保真静态原型，没有依赖安装成本，适合先拿来对方向、讲故事、继续迭代文案。

现在可点的路径
  • 首页 → 附近组局 → 组局详情 → 报名成功 → 组局留言
  • 组局详情 / 留言里的成员 → 成员主页
  • 首页 → 登录 → 发起组局 → 地图选点
  • 首页 / 标签栏 → 登录 → 我的 → 个人资料 / 我的组局
  • 首页右上角 → MVP范围
下一步最值得补的
  • 接入真实地图 SDK、定位权限和 POI 搜索
  • 真正的多屏转场和动效
  • 邀请码、登录态持久化、活动安全提示
  • 把这版转成 React / Vite 项目
